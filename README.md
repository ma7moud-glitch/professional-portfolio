# Professional Portfolio

A responsive personal portfolio built with HTML5, CSS3, Bootstrap 5, and a small amount of JavaScript.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser.
3. For a smoother development workflow, open the folder in Visual Studio Code and use the Live Server extension.

Bootstrap and Google Fonts are loaded from CDNs, so those parts need an internet connection.

## Before submitting
Search the project for `Your Name`, `YourName`, `Your City, Country`, `your.email@example.com`, and `your-username`, then replace the placeholders with your own details.

- Update the education section with accurate details.
- Keep only skills you can honestly discuss.
- The three project cards are explicitly marked as learning project ideas, not completed projects. Replace them with real projects when available, or leave them clearly labeled as ideas.
- Add your actual GitHub and LinkedIn profile links.
- Test on both mobile and desktop.

## Publish with GitHub Pages
1. Create a GitHub account if needed.
2. Create a **public** repository named `my-portfolio` (or another name).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish. The live address will appear on the Pages settings screen and usually follows `https://YOUR-USERNAME.github.io/my-portfolio/`.

## Submission
Submit the **GitHub repository URL** if the instructor asks for the source code. If the form asks for the published website, submit the GitHub Pages URL instead. If unclear, include both.
